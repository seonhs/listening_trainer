# Listening Trainer

**영어 의문문 유형 파악을 위한 리스닝 훈련 프로그램**

## 1. 프로젝트 소개

Listening Trainer는 영어 질문을 듣고 질문의 유형을 빠르게 파악하는 능력을 향상시키기 위한 개인용 리스닝 학습 프로그램이다.

영어 질문을 청취한 후 질문 유형을 선택하면 3초 뒤 정답과 해설을 공개한다. 학습자는 반복적인 청취와 문제 풀이를 통해 질문의 시작 부분을 인식하고, 질문이 요구하는 정보를 예측하는 능력을 훈련할 수 있다.

### 프로젝트 목표

- 영어 의문문 유형을 청취만으로 구별한다.
- 질문의 시작 부분에서 질문의 성격을 빠르게 파악한다.
- 질문 유형에 따라 필요한 정보를 예측한다.
- 취약한 질문 유형을 분석하고 반복 학습한다.
- TOEIC Part 2 청취 능력 향상을 지원한다.

## 2. 핵심 학습 방식

### 기본 학습 프로세스

1. 영어 질문 음성이 자동 재생된다.
2. 학습자는 질문을 듣고 유형을 판단한다.
3. 6개 선택지 중 하나를 선택한다.
4. 질문 종료 후 3초 카운트다운이 진행된다.
5. 정답과 한국어 해설이 공개된다.
6. 다음 문제로 이동한다.

### 정답 공개 규칙

- 답안 선택 시 선택한 유형을 저장한다.
- 3초가 지나면 답안 선택을 마감한다.
- 정답과 해설을 자동으로 공개한다.
- 답안을 선택하지 않았다면 미응답으로 기록한다.
- 정답 공개 후 음성을 다시 들을 수 있다.

## 3. 학습 콘텐츠 구성

### 3.1 기본 의문사 유형

초기 버전은 6개 유형으로 구성한다.

| 유형 | 의미 | 예측 정보 |
|---|---|---|
| Who | 누구 | 사람 |
| When | 언제 | 시간 |
| Where | 어디 | 장소 |
| What | 무엇 | 사물, 내용, 행동 |
| Which | 어느 것 | 선택 |
| Why | 왜 | 이유 |

### 3.2 확장 학습 유형

향후 다음 유형을 추가한다.

| 유형 | 의미 |
|---|---|
| How | 어떻게, 어떤 상태 |
| How much | 가격, 양 |
| How many | 수량 |
| How long | 기간 |
| How often | 빈도 |
| How far | 거리 |

### 3.3 초기 문항 구성

- 기본 질문 유형: 6개
- 유형별 질문 수: 10개
- 전체 문항 수: 60개
- 기본 음성: 미국식 영어
- 기본 재생 속도: 1.0배

## 4. 난이도별 학습 시스템

| 단계 | 학습 내용 | 학습 목표 |
|---|---|---|
| Level 1 | 의문사 소리 인식 | When, Where, Why 등의 첫소리 인식 |
| Level 2 | 의문문을 질문 유형으로 듣기 | 의문사만으로 질문의 방향을 파악|
| Level 3 | 의문문 어순 적응  | 인식할 구조 파악 |
| Level 4 | 전체 의문문 듣기 | 의미 단위 해석 |
| Level 5 | 받아쓰기 | 놓치는 소리 파악 |
### 단계별 세부 내용

**Level 1. 소리 구별**

다양한 의문사 지문에서 의문사를 인식한다.
Who, When, Where, What, Which, Why를 각각 집중적으로 학습한다.

**Level 2. 질문 유형 파악**

| 들리는 표현 |	질문 유형 |
| --- | --- |
| Who |	사람 |
| What |	대상·내용 |
| When |	시간 |
| Where |	장소 |
| Why |	이유 |
| How |	방법·상태 |
| How much |	금액·수량 |
| How long |	기간 |
| Which |	선택 |

**Level 3. 의문문 어순 적응**

| 패턴 |	인식할 구조|
| --- | --- |
| When + do + you |	시간 + 주어의 행동 |
| Where + can + I |	장소 + 가능 |
| Why + did + they |	이유 + 과거 행동 |
| What + is + he |	내용 + 상태·행동 |
| Who + will + attend |	사람 + 미래 행동 |

**Level 4. 의미 단위 해석**

조동사와 주어를 한국어 어순으로 재배열하지 않는다.
문장 끝까지 듣기 전에는 해석을 완성하려고 하지 않는다.

## 8. 질문 데이터 구조

질문 데이터는 JSON 형식으로 관리한다.

### JSON 예시

```json
{
  "id": "WHE001",
  "question_word": "When",
  "question": "When will the meeting begin?",
  "translation": "회의는 언제 시작하나요?",
  "category": "시간",
  "structure": "시간 + 미래 + 장소",
  "audio_file": "WHE001.mp3",
  "audio_speed": 1.0,
  "voice": "US_Female",
}
```

### 데이터 관리 원칙

- 모든 지문은 고유 ID를 가진다.
- 질문 유형과 정답은 일치해야 한다.
- 영어 질문과 한국어 해석을 함께 저장한다.
- 음성 파일은 문항 ID를 기준으로 관리한다.
- 발음 관련 정보는 향후 청취 분석 기능에 활용한다.

## 9. 음원 제작 시스템

문항별 MP3 파일을 자동으로 생성하는 방식을 사용한다.

### 제작 과정

1. JSON에서 영어 질문을 불러온다.
2. TTS API에 질문 문장을 전달한다.
3. 미국식 영어 음성을 생성한다.
4. 생성된 음성을 MP3 파일로 저장한다.
5. 문항 ID와 음성 파일을 연결한다.

### 기본 음성 설정

| 항목 | 기본 설정 |
|---|---|
| 억양 | 미국식 |
| 기본 음성 | 여성 |
| 기본 속도 | 1.0배 |
| 파일 형식 | MP3 |
| 저장 방식 | 문항별 개별 저장 |

이후 버전은 호주식, 영국식 억양 추가, 남성 음성 추가, 1.5배속, 0.8배속 지원한다.

## 13. 향후 확장 계획

### 확장 1. 의문문 유형 확대

How, How much, How many, How long, How often, How far 등을 추가한다.

### 확장 2. TOEIC Part 2 전체 유형

- 일반 의문문
- 선택 의문문
- 부가 의문문
- 제안 및 요청형
- 기타 간접 의문문

### 확장 3. 발음 변별 훈련

질문 유형을 구분하는 것에서 더 나아가 실제 청취 과정에서 발생하는 발음 혼동을 훈련한다.

예시:
- Who와 Where의 시작 소리 비교
- What과 Which의 발음 변별
- 의문사와 뒤따르는 단어의 연결 발음
- 빠른 발화에서 의문사 인식하기

### 확장 4. 개인별 취약점 분석

학습자의 오답 패턴을 분석하고 취약한 질문 유형을 자동으로 출제한다.

### 확장 5. 모바일 학습 환경

스마트폰에서도 사용할 수 있도록 반응형 웹으로 개선한다.

## 14. 프로젝트 개발 원칙

1. 처음부터 모든 기능을 구현하지 않는다.
2. 6문항 프로토타입을 먼저 완성한다.
3. 음성 인식과 문제 풀이의 정상 작동을 우선 검증한다.
4. 검증된 기능을 바탕으로 60문항으로 확장한다.
5. 문항 데이터와 프로그램 코드를 분리한다.
6. 학습 결과를 축적할 수 있는 구조로 설계한다.

## 15. 최종 프로젝트 목표

Listening Trainer의 최종 목표는 단순한 영어 음원 재생 프로그램이 아니다.

영어 질문을 듣는 순간 질문 유형을 인식하고, 질문이 요구하는 정보를 예측하며, 실제 TOEIC 청취 문제에 빠르게 대응할 수 있도록 지원하는 개인 맞춤형 리스닝 훈련 시스템을 구축하는 것이다.
